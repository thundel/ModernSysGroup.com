# ModernSysGroup.com — Enterprise IT Consultancy Platform

ModernSysGroup is an executive technology consultancy web application engineered with a high-impact fusion of **Horizon** (Executive Navy & Deep Cyber Aesthetics) and **Evergreen** (Dynamic Pill UI & Emerald Mint Sustainability).

---

## 🚀 Key Features

- **Single-Page Application (SPA) Architecture:** Lightweight, zero-dependency vanilla HTML5/CSS/JavaScript with 100/100 performance.
- **Dynamic Dual Theme Switcher:** Real-time toggle between **Horizon Executive** (Cyber Cyan / Electric Blue `#00D2FF`) and **Evergreen Elite** (Luminous Mint / Emerald `#7EE0B0`), featuring synchronized logo and favicon states.
- **Dynamic Adaptive Solution Filters:** Inspired by *TheAIFlex*, visitors can focus only on their target domain (`Applied AI & Autonomous Agents`, `Enterprise ERP & Data Lakehouses`, `Cloud & Platform DevOps`, `Full-Stack Cyber & Zero-Trust`).
- **Interactive Deep-Dive Modal Drawers:** Comprehensive service specifications, deliverables, and architecture blueprints accessible without leaving the view.
- **Interactive 4-Step IT Readiness Scorecard:** Instant evaluation calculator with automated readiness grading and tailored strategic recommendations.
- **Responsive & Accessible:** Fluid scaling across all viewports (mobile, tablet, desktop, ultra-wide 4K).
